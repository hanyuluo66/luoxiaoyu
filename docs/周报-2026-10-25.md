# 落小鱼 · 项目周报

**周期**：2026-10-19 ～ 2026-10-25
**项目**：落小鱼 — 微信 AI 自动回复机器人（桌面分身隔离）
**仓库**：https://github.com/hanyuluo66/luoxiaoyu
**本周结论**：v1.0.0 主体完成并可用；核心难点（隔离运行、识图、表情包）全部打通；剩余风险集中在微信登录与网络环境。

---

## 一、本周完成

### 1. 桌面分身：让机器人不抢鼠标（最大难点）

- 微信和机器人运行在**独立 RDP 子会话**（Windows Child Session），有自己的输入队列
- 主桌面打字、全屏游戏、拖窗口都不受影响
- 分身登录体检：`hello_only`（Hello 独占）、凭据是否已存、连续失败计数
- 分身瘦身：登录后自动清掉 Steam / QQ / 网盘 / 驱动托盘等无关启动项（实测 40 → 31 进程）
- 干净启动：建分身**之前**临时挂起用户启动项，登录完成后立刻恢复（主桌面不受影响，失败也会回滚）

### 2. 消息收发

- **收**：解密读取微信 4.x 本地数据库（不点界面、不轮询窗口）
- **发**：UIA 控件写文字 + 回车；图片/表情包走剪贴板（静态图 `SetImage`、GIF 走 `CF_HDROP` 保留动画）
- **切会话**：微信 4.x 会话列表是自绘的（UIA 只能读到导航按钮），改用「搜索框真实按键输入 + 逐行试点列表」
- 群聊三种触发：仅 @我 / 关键词 / 全部消息；配黑白名单、免打扰、频率限制、人工接管、会话冷却

### 3. 识图

- 微信 4.x 图片是 `wxgf`（HEVC）容器 → 用内置 `imageio-ffmpeg` 转标准 jpg → 交给视觉模型
- 实测 `deepseek-chat` 已支持读图，**不用另买 API**
- 新增 `POST /api/vision/describe` 单张图片测试接口

### 4. 表情包

- 自动收藏别人发的表情包（内容哈希去重），控制台有缩略图网格
- 模型用 `[[表情]]` 指令主动发；只写标记时只发表情、不发空文本
- 拒绝兜底：用户要表情包而模型说"发不了" → 丢掉拒绝文字，直接发一张

### 5. 控制台与交付

- 9 个页面：概览 / 私聊 / 群聊 / 规则 / 人设 / AI 接口 / 节奏 / 日志 / 系统设置
- **独立窗口**：Edge `--app` 模式，不再占用浏览器标签页
- 启动进度窗 + 页面进度条；托盘 + 看门狗
- 单文件 exe（78.7 MB，含 ffmpeg），源码已开源

### 6. 安全加固

- 只监听 `127.0.0.1`，加 Host / Origin 校验（挡 DNS rebinding 与 CSRF）
- API Key 不再回传前端（打码 + 留空保存表示不修改）
- 凭据改走 Windows 凭据管理器（`CredWrite`），不再出现在 `cmdkey` 命令行里
- 静态审计：`shell=True` / `os.system` / `eval` 零处，裸 except 零处，SQL 全参数化

## 二、本周攻克的典型问题

| 问题 | 根因 | 解决方式 |
|---|---|---|
| 启动后弹「你的凭据不工作」 | RDP 子会话要密码；账户是 Microsoft 账户且系统开着「仅允许 Hello 登录」 | 关掉 Hello 独占 + 凭据存凭据管理器 + 账户拆成「域 + 用户名」两段（整串会被判为错误密码） |
| 45 秒强制重连把人踢出去 | 引擎在用户输密码时断线重连 | 改为 20 秒显示窗口、90 秒提示、300 秒才重连 |
| 机器人所有发送超时 | 分身里微信停在「进入微信」确认页，UIA 读不到聊天控件 | 启动时和每次发送前自动点掉确认按钮 |
| 收图永远失败 | 用了「消息行」的 local_id，查到的是文字消息 | 改用图片表自己的 local_id，按 `sort_seq` 对齐 |
| 切不到别的会话 | 会话列表自绘，UIA 无列表项；ValuePattern 写值不触发搜索 | 真实键盘输入（SendInput）+ 逐行试点列表 |
| 模型坚称"发不了表情包" | 人设里写明"发不了图片"，且历史里自己说过"发不了" | 改默认人设 + 自动迁移已存配置 + 过滤历史里的旧拒绝 + 流水线兜底 |
| 抢鼠标 | 分身窗口可见时 RDP 把远端光标映射到本机指针 | 任何鼠标/键盘动作前强制 `hide_viewer()` |
| 模型接口连不上 | 系统代理开着但代理程序没运行，httpx 默认走系统代理 | 默认直连，需要代理时在控制台勾选 |
| 启动时黑窗口一闪 | 子进程（whoami/powershell/ffmpeg）各自开控制台 | 全局 `Popen` 子类守卫 + 所有调用走隐藏 spawn |
| `asyncio` 导入崩溃 | 全局守卫把 `Popen` 换成了函数，stdlib 里 `class Popen(Popen)` 崩 | 改成子类实现 |

## 四、风险与遗留

1. **RDP 子会话连接偶发卡住**（`RDP=2` 一直不连上）：Windows 家庭版 Child Session 的固有行为，已加"卡住重启引擎"自愈，极端情况需重启电脑。
2. **首次登录必须人工输一次密码**：登录框在分身的独立桌面，键盘注入进不去。
3. **同一微信号不能两台电脑同时在线**：分身登录后主桌面不要再登同一个号。
4. **git 协议访问 github.com 被墙**：本次推送改用 GitHub API 完成；后续大改动需代理或继续走 API。
5. **代码仓库未含 exe**：release 产物 78 MB，不适合进仓库，需要时本地打包。
