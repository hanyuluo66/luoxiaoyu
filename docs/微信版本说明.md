# 微信版本与运行要求（最新版微信直接可用）

## 结论：不需要降级，用最新版微信 4.x 就行

程序对 **微信 4.1.12+ 已实测通过**（本机验证版本：**4.1.15.53**）。
你现在装的 4.1.15.53 就是可用版本，**不要**降级、**不要**装旧版。

> 早期版本的程序只能配合微信 3.9.x（那时还没找到 4.x 的自动化入口），
> 现在已换成 4.x 方案，3.9 那一套（含版本伪装）全部作废，只留作备用。

## 4.x 是怎么读到界面的（原理）

微信 4.x 的界面是自绘的，直接看只有一个空的 Qt 外壳。但它内部有一个
**Qt 无障碍「闸门」字节**：把这个字节写成 1，界面控件树会立刻变成可读的
`mmui::MainWindow`，搜索框、聊天输入框、会话列表全都能定位。

程序在启动时自动完成这三件事：

1. **找微信进程**：用窗口句柄反查 `Weixin.exe` 的 PID（比进程列表更可靠）
2. **打闸门**：在 `Weixin.dll` 里定位并写入那个字节（只改 1 个字节，不注入代码）
3. **读数据库**：从微信进程内存里取出 SQLCipher 主密钥，解密读取
   `xwechat_files/.../db_storage/` 下的消息库（只读，不改微信数据）

读消息走**本地数据库**（准、快、能读历史），发消息走 **UIA 控件 + 回车**
（不需要 OCR）。

## 运行要求

- Windows 10 / 11
- **微信 4.1.12 或更新**，并且**已登录、窗口保持打开**（可以最小化）
- 程序需要能读取微信进程内存：**不要**用「以管理员身份运行」以外的特殊兼容模式，
  也不要把程序放在被系统限制的目录里运行

### 一个容易踩的坑：程序所在目录的权限标签

Windows 有个「完整性级别」机制。如果程序文件被打了**低完整性标签**，
它就没有权限读取微信（微信是中等完整性），表现是：

- 控制台显示「已连接」，但**会话列表是空的 / 发不出去**
- 日志里出现 `OpenProcess 失败` 或 `open_chat 失败`

检查方法（PowerShell）：

```powershell
icacls "你的\落小鱼.exe" | findstr Mandatory
```

- 输出里**不该**出现 `Low Mandatory Level`
- 如果出现了：把 exe 复制到 `桌面` 或 `C:\` 下的普通文件夹再运行；
  或用 `icacls "落小鱼.exe" /setintegritylevel Medium` 改回来

本包里的 `release\落小鱼.exe` 已经确认没有低完整性标签，可以直接用。

## 首次使用

1. 打开微信并确认已登录（窗口不要关）
2. 双击 `落小鱼.exe`，浏览器自动打开控制台
3. 「概览」页应显示「已连接微信 4.x：<你的昵称>」
4. 进「私聊设置」「群聊设置」，把要自动回复的会话加进名单
   （点「从微信拉取会话」可以直接从微信里选）
5. 「AI 接口」页填 DeepSeek 的 API Key，点「测试连接」
6. 回概览点「启动」

## 已知限制（如实说明）

- **表情/图片/文件消息**：目前只自动回复**文本**消息，其它类型会跳过并在日志里记录
- **发送需要窗口**：发送时程序会把微信窗口抬到前面（会短暂抢占焦点），
  发完自动还原。如果窗口被拖到屏幕外，程序会自动把它移回屏幕中央
- **OCR 相关功能不可用**：本机 Python 3.14 装不了 `winsdk`，所以依赖 OCR 的
  功能（拍一拍、撤回、按「发送」按钮兜底）不可用；**纯文本收发不受影响**
- **微信升级后闸门地址可能变**：升级微信后如果控件树读不到，需要更新
  `wechatauto` 库的版本表
