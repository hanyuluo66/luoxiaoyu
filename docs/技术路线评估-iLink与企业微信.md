# 「落小鱼」技术路线评估：iLink Bot API / 企业微信 / 桌面自动化

> 结论先行：**iLink Bot API 确实存在且官方背书**，但它换来的不是"免费午餐"，而是**能力收缩 + 24 小时重登**。
> 对「落小鱼」目前的能力集合（识图、表情包、多会话群聊）来说，直接迁移 = 功能倒退。
> 建议：**双轨**——保留桌面自动化作为主力，同时把 iLink 做成一个可选适配器，用于"长期在线、只发文字"的场景。

---

## 一、核实结果（2026-10-26）

| 说法 | 核实结论 |
|---|---|
| 腾讯开放个人微信 Bot API（iLink 协议，`ilinkai.weixin.qq.com`） | **真实**。官方 npm 包 `@tencent-weixin/openclaw-weixin`，HTTP/JSON + 长轮询 `getupdates` |
| "不再担心微信更新、无封号风险" | **不完整**，见下方三条硬约束 |
| 企业微信自建应用 / 客服 API 为合规路线 | 真实，但面向企业主体，个人号不可用 |

### iLink 的三条硬约束（来自官方实现文档）

1. **24 小时会话到期**：必须重新扫码；每次扫码 **Bot ID 会变化**。官方实现内置了"剩 2 小时预警 → 用户确认 → 无缝切换"的重连流程，说明这属于常态而非例外。
2. **只能发文本**：图片/语音/文件需要额外的 CDN 加密上传流程，官方 SDK 不提供 → 现有「识图」「表情包」两大功能**直接失去**。
3. **平台可随时变更或终止**，且要求配合内容过滤与限速。

### 能力对照

| 能力 | 桌面自动化（现状） | iLink Bot API |
|---|---|---|
| 文字收发 | ✅ | ✅ |
| 群聊（@我 / 关键词 / 全部） | ✅ | ⚠️ 需确认群聊支持范围 |
| 识别对方发的图片 | ✅（wxgf→ffmpeg→视觉模型） | ❌ 无媒体通道 |
| 发表情包 / 图片 | ✅（剪贴板 + CF_HDROP） | ❌ |
| 历史消息 / 上下文 | ✅（读本地库） | ⚠️ 仅长轮询增量 |
| 不掉线 | ✅（挂着就行） | ❌ 每 24h 重登 |
| 微信更新影响 | ⚠️ 可能失效 | ✅ 不受影响 |
| 违反协议风险 | ⚠️ 存在 | ✅ 官方条款内 |
| 运行环境 | ❌ 必须 Windows + 桌面 | ✅ 任意系统 / 容器 |

## 二、对批评意见的逐条核对

| 批评点 | 是否属实 | 现状 / 处理 |
|---|---|---|
| 比例坐标兜底不可靠 | **属实** | `_open_chat_by_click` 原来用窗口高度 30%~42% 扫行 → **已删除**，改为只认 UIA 真实控件矩形，拿不到就显式降级 |
| 全局挑窗可能操作错窗口 | **属实** | 每次按类名全局枚举 → **已改为显式绑定 HWND**（校验窗口存在 + 类名 + 进程属于微信），失效才重绑 |
| 未确认自动重发会产生重复消息 | **属实** | 原来两轮 UIA + 库兜底 → **已改为单次提交**；回车按下后一律返回「已投递未确认」，绝不重发 |
| 应 OCR 兜底 | **不适用** | 本项目从第一天就关闭 OCR（纯 UIA + 坐标），没有 OCR 链路 |
| 容器化 / 进程外通信 | **部分成立** | 若走 iLink，本来就不需要 Windows（天然解耦）；若留在桌面路线，容器化收益有限（RDP 子会话是环境耦合源，但拆到独立主机即可） |
| 开源诚信（fork 声明 / LICENSE） | **部分成立** | 本项目不是 fork，但**依赖 wechatauto-replica**；LICENSE 已有（MIT），README 已补依赖致谢与上游说明 |

## 三、建议路线

### 阶段 0（已完成，止血）
- 删除比例坐标盲点、显式绑定 HWND、单次提交（不重发）
- README 补依赖致谢与许可证信息
- 控件树冷掉自愈（`_wake_uia`）+ 登录/确认页识别

### 阶段 1（可选，1~2 天）
新增 `ilink` 适配器：
- 复用现有 `build_adapter()` 抽象，配置里可选 `adapter: ilink`
- 只支持文本；收到图片时回一句"看不到图"
- 24h 重连做成控制台提示（不自动弹二维码）
- 价值：给"长期在线、纯文字"的场景一个合规出口

### 阶段 2（按需）
企业微信自建应用：仅当出现"企业客服/私域运营"的真实需求时再做。

### 不建议
为了 iLink 而删掉桌面自动化——那等于放弃识图与表情包，把"能聊天的分身"降级成"文字机器人"。
